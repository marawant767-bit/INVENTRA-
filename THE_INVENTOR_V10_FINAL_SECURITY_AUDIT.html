CLOUD SAVE / SUPABASE

☁️ الحفظ السحابي والمزامنة

اربط مشروع Supabase خاص بك لمزامنة تقدمك بين الأجهزة. لن تعمل المزامنة قبل إدخال بيانات مشروعك وإنشاء جدول قاعدة البيانات الموضح أدناه.

الحالة: غير متصل.

خطوة مهمة: تجهيز جدول Supabase

من لوحة Supabase افتح SQL Editor وشغّل هذا الأمر مرة واحدة:

create table if not exists public.inventor_saves (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.inventor_saves enable row level security;
drop policy if exists "Users manage their own save" on public.inventor_saves;
create policy "Users manage their own save"
on public.inventor_saves for all
using (auth.uid() = user_id)
with check (auth.uid() = user_id);

الأمان: استخدم المفتاح العام anon/publishable فقط. لا تضع service_role أو أي مفتاح سري داخل ملف HTML. المزامنة ترفع نسخة بيانات مساحة العمل المرتبطة بحسابك.
